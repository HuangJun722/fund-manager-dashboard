定投计划

到期不再自动入账：每期到期先生成「待确认」记录，核对实际扣款后再写入账目——系统不替未经核实的事实盖章。

新增定投计划

每月固定日期扣款；当月没有该日期时自动取月末。

主动加仓（定投之外的手动买入）

银行/券商 App 里真实发生的买入，在这里记一笔即成为账目里的真实资产。按金额或按份额都行；扣款可以和定投待确认相互核销——银行已经扣了款，在这里加账并勾选核销，该期待确认就转为真实资产，不再重复催。

计划 vs 账目（怎么分工）

待确认：每期扣款日过后，系统自动生成一条待确认（计划金额 + 当时参考净值），不进账目。你核对银行账单后：确认（可改实际金额/份数）→ 才写流水、改持仓；跳过=银行没扣；未执行=失误漏扣。后两者只留记录。
批量确认：待确认表格勾选多行 → 「确认勾选期次」，一次处理一批，批内逐笔可改。
扣款账户：选一个现金/活期类持仓，确认时从它扣减相同金额；选「新增资金」表示每期是新钱投入，计入外部资金进出。
暂停：保留计划，暂停期间到期期次不生成待确认，恢复后不倒补。
撤销：确认后的流水可在「记账 → 撤销上一笔」撤销（持仓数量一并回滚）。

加密资产文件（手机 / 电脑互传）

把资产用主密码加密成一个文件（portfolio.encrypted.json）。这个文件是密文，放在哪里都安全。 另一台设备打开页面会自动发现它，输入同一个主密码就能看——不需要令牌、不需要账号、不联网同步。
主密码（至少 8 位，忘了无法恢复）
手机怎么拿到数据（不经过 AI，自己就能闭环）
  1. 电脑：点上面「生成加密文件」→ 下载得到 portfolio.encrypted.json
  2. 发到手机：微信文件传输助手 / QQ / 网盘，任选，把文件发到自己手机
  3. 手机：打开本页面 → 设置 → 这里点「从加密文件载入」→ 选刚收到的文件 → 输同一个主密码
这条路完全离线、不经任何服务器。如果让 AI 帮你提交到线上，手机则会自动更新（不用手动传文件）。
⚠ 主密码忘了，加密文件就是永远解不开的乱码，没有找回机制。
保险做法：设置 → 数据备份 →「导出 JSON」→ 把明文文件存到网盘或 U 盘。 平时更新数据后重做一次导出，就永远有兜底。
